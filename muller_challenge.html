MÓDULO 01 · APRENDE

El método de Müller

Un método numérico iterativo para encontrar raíces de una función, aproximando localmente la curva mediante una parábola.

¿En qué consiste?

El método utiliza tres aproximaciones iniciales, \(x_0, x_1, x_2\). Con ellas construye una parábola que interpola los puntos de la función. Luego calcula una raíz de esa parábola y la utiliza como nueva aproximación. El proceso se repite hasta alcanzar la tolerancia deseada.

f(x) ≈ ax² + bx + c

A diferencia de métodos que trabajan solo con valores reales, Müller puede producir aproximaciones complejas cuando la función y los datos lo permiten.

¿Por qué es útil?

01

Flexibilidad: no requiere calcular derivadas de la función.

02

Interpolación: utiliza tres puntos para construir una parábola local.

03

Raíces complejas: puede aproximar soluciones no reales.

04

Iterativo: mejora la aproximación en cada paso, si converge.

La fórmula central, paso a paso

A partir de tres aproximaciones consecutivas, definimos:

h₁ = x₁ − x₀     h₂ = x₂ − x₁
δ₁ = [f(x₁) − f(x₀)] / h₁
δ₂ = [f(x₂) − f(x₁)] / h₂
d = (δ₂ − δ₁) / (h₂ + h₁)

Los coeficientes de la parábola expresados alrededor de x₂ son:

a = (d − δ₂) / (h₁ + h₂)
b = δ₂ + h₂d
c = f(x₂)

El siguiente desplazamiento se calcula usando la raíz cuadrática con el denominador de mayor magnitud para reducir cancelación numérica:

x₃ = x₂ − 2c / (b ± √(b² − 4ac))

Se elige el signo que produzca el denominador de mayor magnitud. Después se actualizan los tres puntos y se repite el proceso.

Condiciones de parada

  • El cambio entre iteraciones es menor que la tolerancia.
  • El residuo |f(x)| es suficientemente pequeño.
  • Se alcanza el máximo de iteraciones.
  • Debe detectarse un denominador nulo o casi nulo.

Ejemplo guiado

Para f(x) = x³ − 2x − 5, una raíz real está cerca de 2.09455. Si se inicia con x₀ = 1, x₁ = 2 y x₂ = 3, Müller construye sucesivas parábolas locales para acercarse a esa raíz.

¿Qué debes observar?

La intersección con el eje horizontal representa una raíz real. Müller no sigue necesariamente una línea recta hacia ella: construye parábolas sucesivas a partir de los puntos disponibles.

Lectura numérica

Residuo = |f(x aproximado)|

Un residuo pequeño indica que la aproximación satisface la ecuación con un error absoluto pequeño. No garantiza por sí solo buena precisión relativa en todos los casos.
